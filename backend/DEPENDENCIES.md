# Project Dependencies (MVP)

## Backend
- fastapi  
  - Web framework for building the API.  
- uvicorn  
  - ASGI server to run the FastAPI app.  
- bcrypt  
  - Secure password hashing (storing user credentials safely).  
- python-multipart  
  - Required by FastAPI to handle form data (e.g., login forms).

## Notes
- SQLite is included in Python by default (no external package needed).
